# Captured examples

Every file here was **generated by running the real pipeline** against the mock
GoHighLevel server and recording what actually crossed the wire.

```bash
python scripts/capture_examples.py
```

Nothing here is hand-written, so it cannot drift from the code and cannot be a
flattering fiction. The `demo` CI job exercises the same code path on every push.

| File | What it shows |
|---|---|
| `01-incoming-webhook.json` | The raw website form post, as received |
| `02-normalized-lead.json` | After normalization — lowercased email, E.164 phone |
| `03-ai-qualification.json` | Schema-validated structured output |
| `04-routing-decision.json` | The deterministic routing decision, with its reason |
| `05-ghl-api-calls.json` | **Every GoHighLevel request and response, captured at the transport layer** |
| `06-webhook-response.json` | What n8n receives back |
| `07-audit-trail.json` | What `GET /admin/events/{id}` returns — steps, timings, outbound calls |
| `08-duplicate-delivery.json` | The same webhook delivered twice: one contact, one upsert call |

The bearer token is redacted in `05`. Everything else is verbatim.

**These are calls to the local mock, not to a live GoHighLevel account.** The
request bodies are exactly what would be sent to `services.leadconnectorhq.com`;
the responses are the mock's, reproducing the documented v2 shapes. See
[`../docs/ghl-integration.md`](../docs/ghl-integration.md).
